# AI4S.github.io
Website AI4S ideation

# How to run the site locally

1. Install Ruby:
   - Download and install Ruby from https://rubyinstaller.org/
   - After installation, run the installer’s post-install steps to add Ruby to your PATH.

2. Install Jekyll:
   - Open PowerShell and run:
     gem install jekyll bundler

3. Install dependencies (if you have a Gemfile):
   - Run:
     bundle install

4. Serve the site:
   - Run:
     jekyll serve
   - Or, if using Bundler:
     bundle exec jekyll serve

5. Open your browser and go to http://localhost:4000

If you encounter errors, ensure Ruby and Jekyll are installed correctly and your PATH is set. For more details, visit https://jekyllrb.com/docs/installation/windows/.
